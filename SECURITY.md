# Security policy

## Reporting a vulnerability

Report security issues through GitHub private vulnerability reporting:

https://github.com/mooplugins/moodle-local_timespent/security/advisories/new

Use that form for suspected vulnerabilities, including access control, data exposure, injection, and resource-consumption issues. Include the product version, what you observed, and steps to reproduce. Proof-of-concept details and suggested fixes are welcome.

Send one report per finding when the issues are independent.

We acknowledge reports on the advisory and agree a publication date with you before anything is made public. Our target is to acknowledge within 3 business days and to ship a fix or a clear timeline within 90 days.

## Public issues

Use the public issue tracker for bugs, privacy questions, and feature requests that do not describe a vulnerability.

## Supported versions

Security fixes are published on the latest release. Older releases in this line should upgrade to that release.

| Version | Security fixes |
| --- | --- |
| 1.3.6 | Supported |
| Older releases | Upgrade to 1.3.6 |

This release supports Moodle 4.5 through 5.2.
